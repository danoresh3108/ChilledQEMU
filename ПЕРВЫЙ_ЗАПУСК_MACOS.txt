ПЕРВЫЙ ЗАПУСК CHILLEDQEUM НА macOS
=================================

Если macOS пишет «повреждён и не может быть открыт» / “is damaged and can’t be opened”,
это метка карантина, которую Finder или Telegram добавили скачанному архиву.

1. Откройте Terminal.
2. Напишите: cd и пробел.
3. Перетащите распакованную папку ChilledQEUM в окно Terminal и нажмите Enter.
4. Выполните ровно эти две команды:

   xattr -dr com.apple.quarantine .
   /bin/zsh "./Запустить.command"

Команда xattr действует только на текущую папку ChilledQEUM. После успешного первого
запуска файл «Запустить.command» можно открывать двойным щелчком.

Если приложение не появилось, пришлите файл launcher.log из папки ChilledQEUM.

Если установлено несколько Python, запускатель сам выберет версию 3.10 или новее и
не будет использовать старый Python из Conda. Конкретный Python можно указать так:

   CHILLEDQEUM_PYTHON=/путь/к/python3.12 /bin/zsh "./Запустить.command"
